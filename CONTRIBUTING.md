# Contributing to International Patient Summary

Thanks for helping improve this project.

## Ways to contribute

- **Report a problem:** open an issue describing what is wrong, unclear, or missing.
- **Fix or improve something:** open a pull request. Small fixes can go straight to a pull request; for larger changes, please open an issue first so we can agree on the approach.
- **Add content or examples:** follow the structure and style of the existing files.

## Development

This repository holds several projects, each with its own `AGENTS.md` and `spec/`; read the root
[AGENTS.md](AGENTS.md) and the project's own before changing it. The "Verify" section of the root
`AGENTS.md` lists the exact lint and test commands per project (viewer, service, website, iOS, Android).
The only root `make` target is `make test-minimum-supported-rust-version`.
